# Aman Shukla - Interactive Portfolio

A sleek, immersive dual-persona personal portfolio. It features a seamless transition between a highly visual Designer layout—showcasing bento-grid case studies and fluid animations—and an execution-focused Developer terminal interface.

## Tech Stack

- **Framework**: Next.js (App Router), React
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Language**: TypeScript
- **Icons**: Lucide React
